# pdftools

Use `C:\Tools\pdftools\pdf.cmd`. Set `[Console]::OutputEncoding = [Text.Encoding]::UTF8`; before piping a job, set `$OutputEncoding = [Text.Encoding]::UTF8`. Prefer `--job FILE`.

Read the verdict and warnings first. Use JSON jobs for anything beyond simple arguments. Look last with `thumb` when text cannot settle a question. Run in the background when the estimate exceeds 90 seconds. Ignore conda's trailing `ERROR conda.cli.main_run` line after a command failure.

Form filling uses `anthropic-skills:pdf`. PDF to Markdown uses the `pdf2md` skill.
