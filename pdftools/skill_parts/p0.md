# pdftools

Use `C:\Tools\pdftools\pdf.cmd`. Set `[Console]::OutputEncoding = [Text.Encoding]::UTF8`; before piping a job, set `$OutputEncoding = [Text.Encoding]::UTF8`. Prefer `--job FILE`.

The result line is the verification: every writing command checks its own output before publishing. On `ok`, report the result and stop; do not open thumbnails, re-extract text or rerun `check` to confirm it. On `warn`, read the warnings and act on them in words. Use `thumb` only when the verdict is `unchecked` or `failed`, or when the user asks to see a page. Use JSON jobs for anything beyond simple arguments. Run in the background when the estimate exceeds 90 seconds.

Form filling, custom-layout PDFs built from scratch, and tables pulled into a spreadsheet use `anthropic-skills:pdf`. PDF to Markdown uses the `md` commands below.
