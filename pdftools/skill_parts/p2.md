## Look at a page

Run `pdf.cmd thumb FILE --page N` to make a PNG in `pdftools\reports` when the user wants to see a page or a verdict is `unchecked`/`failed`; never as a routine check after an `ok` result. Use `--crop X0 Y0 X1 Y1` in displayed millimetres for PDF pages and pixels for images.

Run `pdf.cmd selftest` to check installed capabilities; it prints only failures. `selftest --caps` lists tool paths and versions and library versions.

Treat `ok` as passed and done, and `warn` as passed with warnings to report. `unchecked` means the candidate was published as `_UNCHECKED` after an invariant failed; inspect its warnings and a `thumb` before use. Security check failures publish nothing by default. Read bounded reports from the supplied path and summary.
