## Look and verify

Run `pdf.cmd thumb FILE --page N` to make a PNG in `pdftools\reports`. Use `--crop X0 Y0 X1 Y1` in displayed millimetres for PDF pages and pixels for images.

Run `pdf.cmd selftest` to check installed capabilities; it prints only failures. `selftest --caps` lists tool paths and versions and library versions.

Treat `ok` as passed and `warn` as a result needing review. `unchecked` means the candidate was published as `_UNCHECKED` after an invariant failed; inspect its warnings and a `thumb` before use. Security check failures publish nothing by default. Read bounded reports from the supplied path and summary.
