## Sanitize and redact

- Request to remove active PDF content, attachments, thumbnails or metadata → `sanitize`. Use `--external` to remove URI, Launch, submit and remote actions, and `--multimedia` to remove media objects. `--keep meta,attachments,thumbnails` opts those categories back in. Hidden text and layers that are off are reported but remain in the file.
- Request to permanently remove selected content → `redact --text TEXT`, `--regex PATTERN`, or `--rect page,x0,y0,x1,y1` (displayed millimetres). Add `--pages` to limit pages; `--occurrence N` selects document-order matches for each target. A page with pending redaction annotations needs `--apply-existing` because applying them affects every pending annotation on that page.
- For scanned pages, add `--ocr` and optionally `--lang eng+ind`; it OCRs selected pages with images or no text and combines OCR words with selectable text. Literal targets on OCR text, including an OCR text layer, can use bounded fuzzy matching; a fuzzy match reports its edit distance. Regex matches are never fuzzy. Without OCR, pages with images or vector-like content are reported as unverified; use a rectangle when the scan location is known.
- For several targets, use a JSON job, for example `{"version":1,"input":"report.pdf","steps":[{"cmd":"redact","text":["Ada Lovelace","Charles Babbage"],"regex":["serial\\s+\\d+"],"pages":"1-"}]}`. The job keys match command argument names.
- Both commands accept `-o`, `--each`, password files or environment variables, `--ignore-restrictions`, and `--break-signature`. Never put a password in argv. A `failed` verdict means the checker stopped publication; `--keep-failed` publishes `_FAILED_UNSAFE.pdf` for diagnosis only. Crop is not redaction: cropped content stays in the file.
