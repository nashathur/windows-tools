## Convert documents and inspect images

- Convert an Office document with `pdf.cmd office2pdf FILE`; LibreOffice runs with a fresh profile, macros blocked and link updates off. The result line reports the PDF path, page count and byte size; the verdict is `report` (nothing in the source is compared), so open the PDF only if the user asks about its content.
- Convert a PDF to an editable layout DOCX with `pdf.cmd toword FILE`; `--password-file` or `--password-env` opens encrypted PDFs (the DOCX is then unencrypted: `DECRYPTED_EXPORT` warning), and `-o` selects the destination. Verdict `ok` means the DOCX holds at least 80% of the PDF's words (`LOW_TEXT` warns otherwise); a scanned PDF without text gives `report`.
- Render Markdown with `pdf.cmd md2pdf FILE`; KaTeX handles `$inline$` and `$$display$$` math, local images beside the Markdown are allowed, and remote resources (`REMOTE_RESOURCE`), files outside the Markdown folder (`BLOCKED_LOCAL`) and scripts are blocked. The result is compared with its Markdown source: `ok` is verified, `warn` lists geometry/word-run/image-count notes, and a result named `_UNCHECKED` (exit 3) needs review. `pdf.cmd check PDF --source FILE.md` runs the same comparison on an existing PDF.
- Convert UTF-8 text with `pdf.cmd txt2pdf FILE`; `--mono` uses a monospace font. Long unbroken runs wrap; verdict `ok` means every non-space character of the file is in the PDF.
- Make a PDF from one or more images with `pdf.cmd img2pdf IMAGE...`; folders and globs are natural-sorted (`--sort name|date|exif`; `exif` applies to folders and globs, and a missing date warns `NO_EXIF_DATE`), explicitly listed files keep their order. JPEG, JPEG 2000 and plain PNG/TIFF/GIF data are embedded unchanged and EXIF rotation becomes page rotation; pixels are re-encoded only for mirrored EXIF, `--max-dpi` (downsamples to the placed size; the page size is unchanged; JPEG data that is embedded unchanged is never downsampled), `--lossy` (non-JPEG inputs; alpha kept as a soft mask), `--flatten-alpha`, or formats img2pdf refuses. Other options: `--page`, `--fit`, `--orient`, `--margin`, `--each`, `--ocr`, `--toc`. Several inputs are named `<folder or first image stem>_images.pdf`. RAW and JPEG XL files in a folder are left out with `SKIPPED_UNSUPPORTED`; an SVG page that renders blank warns `SVG_BLANK`. Verdict `ok` means page count and embedded pixel sizes (after `--ocr`, of the OCR output) were verified and SVG pages render something.
- Export embedded PDF images with `pdf.cmd images FILE`; each image is written once (inline images as `inline_NNN`), `--min-px` skips small items, and the result points to the folder `<stem>_images` with an `images.json` manifest. Warnings: `DECRYPTED_EXPORT`, `IMAGE_FAILED` (that image skipped, the rest published), `SKIPPED_TOO_BIG`, `UNVERIFIED_IMAGE`.
- Read image text with `pdf.cmd imgtext IMAGE`; `--lang` defaults to `eng+ind`; any image Pillow reads works (HEIC, WebP, PSD, EPS, SVG are converted first), and `-o FILE` also writes the text to a `.txt` file. The report includes OCR text and the mean confidence of words with confidence ≥ 0.
- Inspect an image with `pdf.cmd imginfo IMAGE`; the report includes dimensions, DPI, mode, bit depth, ICC and EXIF details.
- Compare images with `pdf.cmd imgdiff A B`; different sizes are reported, and `--resize` aligns them before tile comparison.
- Export PDF pages with `pdf.cmd toimg FILE`; `--format` accepts PNG, JPEG (`jpg`), WebP, TIFF (`tif`), BMP, GIF, AVIF, HEIC (`heif`) and SVG, and files use that format's extension (a multi-page export goes to the folder `<stem>_<ext>`, e.g. `doc_jpg`). `--format tiff --single` writes one multipage `<stem>_single.tiff`. `--format svg` keeps vector content with text as paths (`--svg-text` keeps real text and warns that it needs the fonts) and refuses `--clip`, `--gray`, `--bw`, `--dpi`, `--alpha`, `--stitch`. `--quality`, `--lossless`, `--tiff-compression`, `--alpha`, `--clip`, `--gray`, `--bw`, `--pages`, `--stitch` and `--grid` apply as supported by the selected format. Raster exports are verdict `ok` after each written image is reopened and its size checked; SVG exports are `report`.
