## Edit and stamp

- `meta` reads, writes, clears or transfers Info/XMP metadata and `/Lang`; use `--to` to export JSON and `--from` to patch it. The result line reports pages and verdict; check metadata independently after edits.
- `bookmarks --list|--set JSON|--clear` manages the outline. `labels --set JSON` applies page labels; the JSON uses 1-based `from` and `start` values.
- `protect` applies AES-256 permissions and `unlock` writes an unencrypted copy. Input passwords use `--password-file` / `--password-env` and `--owner-password-file` / `--owner-password-env`. New protect passwords use `--new-password-file` / `--new-password-env` and `--new-owner-password-file` / `--new-owner-password-env`; never put passwords in argv.
- `watermark`, `numbers`, and `headfoot` stamp selected pages. Use nine anchors for watermarks and numbers; templates accept `{n}`, `{total}`, `{date}`, `{file}`, and page labels where supported.
- `annotate` highlights, underlines, strikes, or regex-matches text, adds notes or geometry, lists annotations, or removes by ID. Regex annotations use line quads. Read the per-page match counts and verdict.
- `flatten` bakes annotations and form widgets; `--only` selects a kind and `--raster DPI` rasterizes pages. Raster output reports `TEXT_RASTERIZED`.
- `crop` changes the visible crop box only; cropped content remains in the file. `cut`, `resize`, `nup`, and `booklet` create new page layouts; these may drop links, annotations and fields. Read any `FEATURES_DROPPED` warning. `--flatten-annots` bakes marks before layout.
- `gray` converts pages to grayscale. `rmblank` removes high-confidence blank pages and keeps uncertain pages unless `--include-uncertain` is set.
- `rename` previews safe filenames by default. Use `--apply` to rename and write a manifest; `rename --undo MANIFEST` restores files when their identity matches. `repair` attempts to recover a damaged PDF.

Read verdicts and warnings first. Use JSON jobs for lists and values that need spaces. A `warn` verdict means the output was published with warnings; `unchecked` means the built-in invariant failed and the output name ends in `_UNCHECKED`.
