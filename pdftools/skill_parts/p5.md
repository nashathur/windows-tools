## Compress, OCR, and batch

- Use `compress FILE` to reduce size. `--level lossless|med|high|max` selects a quality target; `--target SIZE` tries levels in order until it reaches the byte target. `--include-graphics` also recompresses lossless, bitonal, and indexed images and allows the more aggressive Ghostscript and OCRmyPDF optimizers. Without it those graphics are left alone. Read the result note for bytes, method, and changes. `NO_GAIN` means the input was already smaller than every passing candidate; the result path is the original file.
- Use `ocr FILE` to add a searchable text layer. By default it measures scanned pages, enables page rotation correction, deskews when a page is tilted, oversamples scans below 250 effective dpi, and uses Sauvola thresholding when the background illumination varies. Use `--clean` only on Linux with `unpaper` installed; it opts into OCRmyPDF's `--clean` image cleanup. `--lang` accepts Tesseract language codes joined with `+`; it defaults to `eng+ind`. Use `--pdfa` only when a PDF/A output is wanted. Pages that already contain text are skipped; inspect `OCR_EMPTY` pages when OCR could not produce text. `OCR_LOW_QUALITY` warns about scans below 150 effective dpi, while `OCR_EMPTY` reports pages still without text. Result records include the selected `preprocess` options, per-page `page_measurements` (effective dpi, skew, background spread, mean brightness, small noise blobs, and uneven/dark flags), displayed `rotated` page numbers, and `deskewed` pages with measured angles. Mostly dark pages are reported for follow-up; automatic inversion is not applied. If OCRmyPDF exceeds its time limit, the command reports `TIMEOUT` and does not publish a partial result.
- Use `batch FILE "rotate --by 90 | numbers | compress --level med"` for a short pipeline. For paths, recipes, or values containing spaces, use a JSON job such as `{"version":1,"input":"report.pdf","steps":[{"cmd":"rotate","by":90},{"cmd":"compress","level":"med"}]}`, run with `pdf.cmd batch --job FILE`. Each step inherits the batch input and output. A `NO_GAIN` compress step passes its input on to the next step. `protect` can appear only last; put its new password in that protect step's own `password_file` / `password_env` and `owner_password_file` / `owner_password_env` keys. `--dry-run` validates and prints the plan without creating outputs.
- Use `compress --each FOLDER`, `ocr --each FOLDER`, or `batch --each FOLDER "rotate --by 90"` to process a set of PDFs. The shorthand `--each GLOB_OR_FOLDER` form is also supported by all three commands. Batch reports one result per file and exits 4 if any file fails.

All three commands accept `-o`, `--password-file` / `--password-env`, `--owner-password-file` / `--owner-password-env`, `--ignore-restrictions`, and `--break-signature`. Never put a password directly in an argument. A result named `_UNCHECKED` needs review; exit 3 means its invariant check did not pass.
